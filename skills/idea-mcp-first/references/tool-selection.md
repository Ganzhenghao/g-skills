# IDEA MCP 默认工具筛选

本清单依据注册工具的名称、参数和返回结构制定；不代表速度、行为或 token 收益已实测。默认原生终端、Git 和文件编辑工具可用。

## 本次注册核对

当前可见 22 项工具：建议保留的 20 项全部存在，待移出的仅剩 `get_file_problems`，另有不纳入判断的 `execute_tool`。原方案中其余 8 项已不再注册：`git_status`、`execute_terminal_command`、`create_new_file`、`open_file_in_editor`、`create_changelist`、`move_changes_to_changelist`、`set_active_changelist`、`delete_changelist`。

## 应用方式与边界

- [tool-profile.json](tool-profile.json) 是客户端无关的工具筛选数据，名称省略服务前缀；它不是可直接导入的 MCP 配置，也不会被技能自动执行。
- `retain` 是建议保留注册的 20 项工具，`excludeFromDefault` 是当前仍待移出的 1 项工具。将名称映射到当前服务实际暴露的名称后，使用该环境已有的服务端或客户端过滤机制应用；再次调整注册后重新核对清单。
- `outOfScope` 中的 `execute_tool` 不作保留或删除判断；不要用 20 项保留名单对它作隐式删除决定。新增或未知工具需要重新评估。
- 仅在用户授权的配置范围内调整过滤层。本仓库不包含 MCP 服务端或客户端过滤配置，修改技能不代表获准更新安装目录或客户端配置；本次实际注册变化来自用户在仓库外的调整。
- 若客户端没有工具过滤能力，仅落实技能路由，不伪造配置字段、代理服务或过滤成功结果。技能中的不调用规则不会移除工具 schema；实际上下文成本还取决于客户端的加载方式。
- 当前独立注册的调试工具为零。技能不提供调试流程，其他环境即使暴露调试工具也不使用；普通运行与测试工具保留。

## 筛选理由

优先保留符号定位、声明信息、调用层级、语义重命名、依赖源码读取和批量检查。文件及文本搜索保留用于定位；需要匹配行上下文时，原生 `rg` 可能更直接，不能仅凭 IDE 索引判断 token 收益。

模块、依赖、VCS 根、编辑器上下文和目录树均按需查询。格式化、构建及运行只在任务需要时使用。`get_changelists` 保留 IDEA 独有的分组读取能力，检查归属时遵守“不提交的变更”等规则。

| 移出默认注册 | 替代或原因 |
| --- | --- |
| `get_file_problems` | 单文件和批量统一使用 `lint_files` |

## 验收

- 核对清单的 20/1/1 数量、互斥性及名称与当前 22 项注册接口一致，保留普通运行和测试能力。
- 对相同任务分别记录优化前后的调用次数、返回内容量及实际可取得的 token 数据，同时核对答案和验证完整性；没有测量时不宣称性能提升。
- 覆盖项目符号、依赖源码、调用树续查、重命名、批量检查及定向测试；超时、截断、未分析或部分写入不能被误报为成功。
- 结构校验不代替实际注册核对或客户端行为验证。
